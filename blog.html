O que aprendi sobre lógica de programação

Antes de escrever qualquer código, eu preciso entender o problema. Esse foi o principal aprendizado em Lógica de Programação I. Um algoritmo não começa no computador, mas na forma como divido uma situação em entradas, processamento e saídas.

Ao praticar variáveis, condicionais e repetições, percebi que o código fica mais fácil quando penso em passos pequenos. Se uma decisão depende de uma nota, por exemplo, posso testar se a média é suficiente antes de mostrar o resultado. Essa sequência torna o raciocínio mais claro e evita erros.

Também aprendi que testar faz parte do processo. Um programa que funciona apenas em um caso ainda precisa ser verificado com valores diferentes. Essa atenção ajuda a criar soluções mais confiáveis.

Informática 29/05/2026

Por que organizar arquivos muda o desenvolvimento

No início, parece mais rápido colocar todos os arquivos na mesma pasta. Depois de alguns testes, fica difícil encontrar imagens, folhas de estilo e scripts. Por isso, a organização do projeto é um requisito importante.

Separar HTML, CSS, JavaScript e imagens cria uma estrutura lógica. Quando o site cresce, essa divisão ajuda a localizar problemas, trocar arquivos e publicar o projeto em serviços como o GitHub Pages.

Essa organização também comunica cuidado. Quem abre o projeto consegue entender rapidamente onde está cada parte, o que facilita manutenção e avaliação.

Web 25/05/2026

Primeiros passos com HTML, CSS e JavaScript

HTML, CSS e JavaScript formam a base de um site. O HTML organiza o conteúdo com títulos, parágrafos, links, listas e formulários. O CSS cuida da aparência, como cores, tamanhos, espaçamentos e adaptação para celular.

O JavaScript adiciona comportamento. Neste portfólio, ele controla o menu em telas menores, destaca a navegação atual e valida o formulário de contato antes do envio.

Entender a função de cada linguagem ajuda a escrever código mais limpo. Quando cada arquivo cumpre seu papel, o projeto fica mais simples de evoluir.
